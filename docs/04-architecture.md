## Request paths

Two paths, each with an AI stage followed immediately by a deterministic check.

```
REQUEST   speech ─► useSpeech ─► IntentController
                                      │
                                 IntentService      (Gemini, schema-bound)
                                      │
                                 IntentValidator    (closed set; reject on miss)
                                      │
                                 RoutingService     (pgr_dijkstra + profile cost)

RESPONSE  RoutingService ─► InstructionBuilder      (segments + landmarks)
                                      │
                           InstructionGenerator     (Gemini, phrasing only)
                                      │
                           InstructionVerifier      (named landmark must exist)
                                      │
                           TemplateInstructionWriter on failure
                                      │
                                 useSpeech ─► spoken output
```

The model never calls the database, never selects a landmark, and never
computes a path. Removing it degrades the system to template phrasing rather
than breaking it.
